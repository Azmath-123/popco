# PopCo India - Frontend Storefront

Modern e-commerce storefront for **POP CO India**, crafted with React, Vite, Tailwind CSS, and Lucide icons.

## Features
- **Signature Product Range**:
  - **Premium Raw Makhana** (Jumbo 6+ Suta)
  - **Roasted and Salted Edamame Beans** (46% Plant Protein)
  - **Masala Tea** (Coming Soon)
- **Interactive Header & Navigation**:
  - Desktop hover mega-dropdown showcasing product images, pricing, and direct routing.
  - Responsive mobile menu with expand/collapse product accordion.
- **Storefront & Ordering Experience**:
  - Live cart drawer with bulk order custom combo discount engine.
  - Product detail pages with image galleries, pack selectors, and verified reviews.
  - FAQ, wholesale bulk enquiry modal, and WhatsApp integration.

## Deploying on Vercel
1. Import this repository into Vercel.
2. Framework Preset: **Vite** (auto-detected).
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. *(Optional)* Set `VITE_API_BASE_URL` to your production backend API. If left unset, the storefront smoothly loads the initial catalog data for live client preview.
